# Conformance

This directory is the repository-local executable evidence boundary for the MCP template. It tests the independently authored TypeSpec and JSON Schema authorities plus implementation behavior; it is not a third contract authority.

`check.sh` is the stable Zed/Git lifecycle entrypoint. CI may run deeper pinned shared-runner/IR evidence, but local admission must still prove peer-authority parity and Rust tests without relying on sibling checkouts.
